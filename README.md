VELDARA — a travel poster for an island that does not exist: white chalk cliffs, a lone red-and-white lighthouse, and a turquoise sea at golden dusk. The poster is generated as a 1024×1024 image that leads the eye from the name to the lighthouse to the horizon.

The entry image is `entry.png` (1024×1024, PNG). `main.py` is standard-library only: it copies the stored poster to `$MAKEFUN_OUTPUT_DIR` and verifies the copy with sha256, so the program runs offline in the sandbox with no network and no image tooling.

## Run it

```sh
python3 main.py
```
